# 산사의 하루

산사를 걸어 다니며 도연 스님과 이야기하는 작은 브라우저 게임입니다. 스님은 **내 컴퓨터 안에서 도는 AI**(Gemma 4 E2B)로 대답하고, 말한 대로 따라오거나 연못에 같이 가거나 심부름을 부탁합니다. 서버로 대화가 나가지 않습니다.

## 조작

| 키 | 동작 |
|---|---|
| WASD / 방향키 | 이동 |
| Shift | 달리기 |
| Space (또는 E) | 말 걸기, 우물에서 물 긷기 |
| Q | 스님에게 빙의 / 해제 |
| Tab | 관찰 모드 (전체 산사 보기, 시점 회전, 확대) |
| 대화창에서 1 / 2 / 3 | 추천 대사 고르기 |
| Esc | 대화창 닫기 |

## AI 스님 깨우기

처음엔 정해진 대본으로 대답합니다. 오른쪽 위 **AI 스님 깨우기**를 누르면 모델(약 2.7GB)을 한 번 받고, 다음부터는 브라우저에 저장된 것을 씁니다.

- 필요: 데스크톱 **Chrome 또는 Edge** (WebGPU). 맥북 M 시리즈, 최근 그래픽카드가 있는 PC에서 잘 돕니다.
- 지원하지 않는 기기에서는 대본 스님이 계속 대답합니다. 게임은 그대로 할 수 있어요.

## 해 볼 것

- 스님에게 "따라와 주세요", "연못 같이 가요", "도울 일 있을까요?"라고 말해 보기
- 스님의 부탁 들어주기 (우물은 동쪽 밭 옆)
- Q로 스님이 되어 산사 돌아다니기

## 개발

```bash
npm test                  # Node 테스트 (DOM 없는 모듈)
python3 -m http.server 8000   # http://localhost:8000
```

개발 중에는 모듈 캐시 때문에 화면이 멈출 수 있으니 강력 새로고침(Cmd+Shift+R)을 쓰세요.
