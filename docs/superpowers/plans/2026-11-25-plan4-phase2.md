## Part A — Codex (브랜치 `plan4-play`, worktree `~/Projects/sansa-game-play4`)
소유: `index.html`, `src/render.js`, `src/viewer.js`, `src/player.js`, `src/control.js`, `src/play.js`, `src/dialogue-view.js`, 새 파일 `src/journal-view.js`, `src/easter.js`, 해당 tests. **game.js·brain·lines·memory·errands·llm은 건드리지 않는다**(echo 임시본도 만들지 말 것 — game.js는 이미 있다. 계약의 새 메서드를 game.js가 아직 안 써도 Play는 동작해야 한다).

1. **동물 빙의:** Q 순환 visitor→monk→dog(황구)→white(백구)→cat(고양이)→visitor. control.js의 조종권 이전 규칙(공동 활동 종료·AI 보류·해제 시 재개)을 동물에도 적용. 동물 속도: 개 2.6, 고양이 2.4 타일/초(Shift ×1.6). 빙의 중 원본 자세(걷기·앉기) 유지. 카메라·HUD 힌트·"주인공" 렌더 통일을 동물까지. 테스트: 각 동물 빙의 30초 동안 다른 NPC와 시계가 움직임, 해제 후 원래 AI 재개, 황구–백구 합동 놀이 중 빙의해도 상대가 갇히지 않음.
2. **상호작용 대상 확장:** Target = monk|dog|white|cat|well|field|kitchen. 조종 중인 캐릭터가 스님이 아니면 Space/E로 발생(자기 자신 제외). 동물 대상 거리 ≤2, 경로 ≤4. `field` = 익은 밭(`s.farm[i].stage==='ripe'`) 접근 타일, `kitchen` = 공양간 문 앞. `setTargetEnabled`로 well/field/kitchen 켜고 끔(기본 꺼짐 — 플레이테스트에서 부탁 없이 "물 긷기"가 뜨던 문제 해결).
3. **AnimalHandle** (`Play.animals`): tile, possessed, say(말풍선), emote(원본 자세 재사용: 개 wag=꼬리, sit=rest, jump=invite, sniff, 고양이 purr=nuzzle/blink), hold.
4. **스님 위치 표시:** 스님이 화면 밖이면 화면 가장자리에 작은 화살표 + "스님" (플레이테스트: 스님을 찾기 어려움). 빙의 중 대상이 스님이면 숨김.
5. **일지 패널** (`src/journal-view.js`): J로 열고 닫기, `onJournal` cb가 준 `JournalEntry[]` 표시. 파스텔 Ⅱ 톤, 대화창과 같은 계열 디자인. Esc 닫기, 열려 있으면 이동 막음.
6. **모델 선택** (`modelPicker`): 우상단 버튼을 누르면 작은 메뉴에 choices 표시(예: "가볍게 · 1.1GB", "똑똑하게 · 2.7GB"), 고르면 onPick(id), 이후 setText/hide로 진행 표시.
7. **종루 이스터에그** (`src/easter.js`): 종루(halls name '종루') 근처에서 Space → 타종음(Web Audio 합성, 은은하게) + 화면 살짝 흔들림 → 산문에서 **오리지널 꼬마 캐릭터 3종**이 걸어 들어와 마당을 한 바퀴 돌고 퇴장(약 25초). 우상단 山 도장 5번 연속 클릭으로도 발동. 캐릭터: 원본 픽셀 그림체로 새로 디자인 — 동글고 작은 2~3등신, 예: "솔방울 요정", "연잎 토끼", "동자 꼬마". **기존 IP 캐릭터를 닮게 만들지 말 것**(공개 저장소). 쿨다운 60초.
8. **원인 미상 버그 확인:** 초기 플레이 중 관찰 모드·빙의가 저절로 바뀐 적 있음(재현 실패). 입력 처리에서 의심 경로(예: 포커스 이동 중 Tab/Q keydown, 버튼 포커스 상태의 Space가 버튼 클릭으로 처리)를 점검하고, 재현되면 테스트로 고정.

테스트: `npm test` 전부 통과(현재 159). 브라우저 확인은 Claude가 한다. 커밋 규칙·보고서 형식은 Plan 2와 같음(`docs/review/plan4-report.md`). Codex 샌드박스가 git index를 못 쓰면 커밋하지 말고 파일만 남길 것.

## Part B — Claude (브랜치 `plan4-brain`, worktree `~/Projects/sansa-game-brain4`)
소유: `src/game.js`, `src/brain.js`, `src/actions.js`, `src/lines.js`, `src/memory.js`, `src/errands.js`, `src/llm/*`, 새 파일 `src/journal.js`, 해당 tests.

1. **동물 대화:** 방문객(또는 빙의한 캐릭터)이 동물에게 Space → 대화창(이름: 황구/백구/고양이). 그 동물 호감도 `close` 미만이면 LLM 없이 대본: 소리+행동 묘사(예: "멍! (꼬리를 흔들며 손 냄새를 맡는다)") + `emote`. `close` 이상이면 LLM, 동물 페르소나(짧고 순박한 말투, 동물다운 관심사). 호감도는 동물별 memory(쓰다듬기 대화 +1, 하루 상한 3). 동물 행동은 `none`만(움직이는 행동은 2단계에서 제외).
2. **빙의해서 스님과 대화:** 동물에 빙의한 상태로 스님에게 Space → 스님이 그 동물에게 말하는 톤(`partner`). 스님 행동 중 offer_errand는 방문객일 때만.
3. **일지** (`src/journal.js`): `onJournal`에 오늘 날짜 기준 항목 — NPC별 만남 수·호감도 구간·완료한 부탁·최근 한 줄. 순수 함수 `buildJournal(memory) → JournalEntry[]`.
4. **모델 선택:** `modelPicker([{id:'gemma-4-E2B-it-q4f16_1-MLC',label:'똑똑하게 · 2.7GB'},{id:'Qwen3.5-2B-q4f16_1-MLC',label:'가볍게 · 1.1GB'}])`. 고른 모델로 load. 마지막 선택을 localStorage에 기억. Play에 modelPicker가 없으면 modelButton으로 폴백(병합 순서 무관하게 동작).
5. **부탁 추가 — 채소 나르기:** 들밭에서 익은 채소 거두기(`field`) → 공양간(`kitchen`)에 가져다 놓기. `setTargetEnabled`로 단계별 대상 켜기(물: well, 채소: field→kitchen). errands.js를 부탁 종류별 상태 기계로 일반화, 보상 1회.
6. **플레이테스트 개선:** 부탁이 없을 때 well/field/kitchen 끄기.

테스트: 가짜 Play에 새 메서드 추가, 각 항목 Node 테스트. 커밋은 작은 단위.
