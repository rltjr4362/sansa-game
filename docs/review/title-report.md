# 시작 화면 구현 보고서

`title-play` 워크트리에 `Play.showTitle(choices, onStart)`와 `TitleHandle`을 구현했다. 페이지의 기존 진입점에서 `game.js`가 동기적으로 호출하면 첫 렌더링부터 시작 화면이 표시된다. 호출이 없는 현재 `game.js`로는 바로 플레이가 시작된다.

## 구현

- `index.html`과 `src/title-view.js`에 파스텔 Ⅱ 색상, 바탕 계열 제목, 반투명 카드, 추천 배지, AI 미지원 안내, ‘AI 없이 시작’ 버튼을 추가했다. 카드 그리드는 좁은 폭에서 한 열로 접히고, 내용이 화면 높이를 넘으면 모달 안에서 스크롤할 수 있다.
- 네이티브 모달을 열고 HUD, 도크, 모델 버튼을 포함한 게임 UI를 숨긴다. 첫 카드에 포커스를 주고, `setSelected`가 호출되면 지정된 항목에 강조와 포커스를 함께 옮긴다. 방향키와 Tab은 활성 항목을 순환하고 Enter는 강조된 항목을 실행한다. AI가 비활성화되면 ‘AI 없이 시작’으로 이동할 수 있다.
- `src/play.js`와 `src/viewer.js`에서 기존 관찰 모드의 카메라 회전을 재사용한다. 시작 화면에서는 진입 즉시 첫 회전을 시작하고 이후 8초 간격으로 전경을 돌린다. `onStart`는 선택한 AI의 ID 또는 `null`을 한 번 전달한다. 260ms 페이드가 끝나면 플레이 입력을 복구하고 방문객을 2.5배로 줌한다. 모션 감소 설정에서는 회전과 페이드 및 줌 보간을 생략한다.

## 검증

- `npm test` 248개 통과, 실패 0개. 시작 화면 테스트 6개를 추가했다.
- Node의 DOM 및 렌더러 대역으로 기존 즉시 플레이, 시작 화면 회전과 입력 차단, 페이드 후 방문객 줌과 일지 입력 복구, 모션 감소 설정에서의 즉시 전환을 확인했다.
- **브라우저 미확인.** 샌드박스에서 로컬 서버 실행이 차단됐고 Chrome, Safari 및 인앱 브라우저에 연결할 수 없었다. 모바일 화면의 실제 렌더링과 네이티브 모달의 포커스 동작은 브라우저에서 검증하지 못했다.
- 샌드박스가 Git `index.lock` 생성을 막아 변경 파일을 워크트리에 남겼다.
