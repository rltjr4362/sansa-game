# Plan 2 플레이 흐름 구현 보고

## 구현

- 산문 뒤의 걷기 가능한 타일 `(12.5, 19.5)`에 배낭을 멘 방문객을 배치했다. WASD와 방향키로 화면 방향에 맞춰 초당 약 1.1타일 이동한다. 이동 중 통과하는 타일을 축별로 검사해 벽을 따라 미끄러질 수 있고 대웅전의 열린 문턱을 통과할 수 있다.
- E는 2타일 이내이며 경로가 4타일 이하인 스님과 4방향 인접 타일에 있는 우물 중 가까운 대상을 선택한다. 동거리에서는 스님을 우선한다. 임시 게임은 스님 대화에 입력을 그대로 표시하고, 우물에서는 도착 안내를 표시한다.
- Q로 빙의하면 방문객은 그 자리에 서고, 스님의 공동 행동을 정리한 뒤 일과만 보류한다. 시계, 날씨, 농사, 템플스테이 손님, 동물은 계속 갱신된다. 해제하면 현 위치에서 가장 가까운 일과 접근 타일로 재탐색한다. 농사 일과는 원래 담당 밭의 접근 타일로 돌아가고, 도달할 수 없거나 이미 완료한 일과는 원본 스케줄러가 새로 고른다.
- `MonkHandle`의 따라가기, 장소 이동, 현재 위치 기반 스냅샷, 말풍선을 구현했다. 플레이 카메라는 2.5배로 현재 조종 중인 캐릭터를 추적하며 관찰 모드에서 돌아오는 순간의 각도를 고정한다.
- 원본 설정, 음악, 환경음, 독송과 관찰 조작을 옮겼다. Tab 또는 모드 버튼으로 관찰 모드에 들어가면 휠, 핀치, 드래그, 구역 선택, 시점 회전과 기존 교감 메뉴를 쓸 수 있다. 플레이에서는 E와 Q를 사용한다.
- 방문객과 스님을 같은 방 점유 및 깊이 정렬 경로로 그린다. 원본의 픽셀 복원 창과 손님 별도 복원 대신, 현재 주인공 앞의 가림 물체만 국소적으로 투명하게 그리도록 바꿨다. 대화창은 파스텔 Ⅱ 색상에 맞췄고, 추천 1/2/3, 자유 입력, IME, 응답 선택, 생각 중 표시, 상태 줄, Esc 닫기를 지원한다.

## 검증

- `npm test` — ℹ pass 44 / ℹ fail 0. 기존 24개와 신규 20개가 통과했다. 원본과 `src/world.js`의 720초 기준선도 통과했다.
