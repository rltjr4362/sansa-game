# Plan 4 Part A 구현 보고

## 구현

- Q로 방문객 → 스님 → 황구 → 백구 → 고양이 → 방문객 순으로 전환한다. 빙의할 때 관련 공동 활동을 끝내고 해당 캐릭터의 AI를 보류한다. 시계와 나머지 NPC의 시뮬레이션은 계속 진행된다. 해제하면 현재 타일에서 이전 목적지로 길을 다시 찾거나 원본 AI가 다음 행동을 고른다. 황구가 보류되어 합동 놀이를 할 수 없는 동안 백구는 원본의 솔방울 놀이를 혼자 할 수 있다.
- 개는 초당 2.6타일, 고양이는 2.4타일 걷고 Shift를 누르면 1.6배 빨라진다. 현재 캐릭터를 2.5배 플레이 카메라가 추적하며, 동물도 원본 걷기·앉기 자세와 주인공 가림 처리, HUD 안내를 쓴다. 스님이 화면 밖이면 가장자리에 방향 화살표를 표시한다. 스님을 조종하는 동안에는 숨긴다.
- Space/E로 스님, 황구, 백구, 고양이에게 말을 걸 수 있다. 조종 중인 자신은 제외하고, 스님을 조종할 때는 대상 콜백을 보내지 않는다. 동물은 거리 2타일, 경로 4타일 제한을 적용한다. 우물은 4방향 인접 타일, 밭은 익은 작물의 접근 타일, 공양간은 바깥쪽 문 앞 타일에서 상호작용한다. 세 대상은 초기 상태에서 모두 꺼져 있으며 `setTargetEnabled`가 표시와 입력을 함께 제어한다.
- `Play.animals`에 위치, 빙의 상태, 말풍선, 3초 제스처, 제자리 대기를 연결했다. 동물은 대기 동안 현재 조종 캐릭터를 바라보며, 다시 호출하면 대기 시간이 연장된다.
- J로 일지를 열 때마다 `onJournal`이 반환한 항목을 읽는다. J, Esc, 닫기 버튼으로 닫을 수 있고 열려 있는 동안 이동과 빙의를 막는다. 우상단 모델 메뉴는 선택 ID를 콜백에 전달하고 `setText`와 `hide`로 진행 상태를 표시한다. 기존 모델 버튼도 사용할 수 있다.
- 종루 근처에서 Space를 누르거나 우상단 山 도장을 연속으로 다섯 번 누르면 타종음과 짧은 화면 흔들림이 재생된다. 솔방울 요정, 연잎 토끼, 동자 꼬마 픽셀 캐릭터가 산문에서 들어와 앞마당을 돌고 약 25초 뒤 퇴장한다. E는 다른 상호작용 대상이 없을 때 타종한다. 도장 클릭 간격은 최대 1.2초이며 두 발동 경로는 시뮬레이션 시간 기준 60초 쿨다운을 공유한다. 동작 줄이기 설정에서는 화면 흔들림을 생략한다.
- 버튼에 포커스가 있는데 Q가 빙의를 바꾸고 Space가 상호작용을 실행하는 경로를 재현했다. 게임 단축키를 장면에 포커스가 있을 때만 처리하고 포커스가 이동하면 눌린 이동 키를 비운다. 장면을 클릭하면 게임 단축키를 다시 쓸 수 있다. 초기 플레이 중 모드가 바뀌었다는 제보는 같은 상황으로 재현되지 않아 원인은 미확정이다.

## 검증

- `control`과 `player`의 Node 테스트를 먼저 추가해 변경 전에 실패를 확인했다. 이후 동물별 30초 빙의와 AI 재개, 황구·백구 합동 놀이 정리, 말풍선·제스처·대기, 대상 범위·토글, 포커스 제어가 통과했다.
- `npm test` 결과는 **ℹ pass 176 / ℹ fail 0**이다. 기존 720초 원본 시뮬레이션 기준선과 종루 행렬·쿨다운 테스트가 포함됐다.
- 임시 Node DOM/Canvas 스모크에서 기존 게임 초기화와 스님 대화, Q와 Tab 전환, 일지와 이동 차단, 모델 선택, 우물·밭·공양간 토글, 동물 말풍선, 도장과 Space 타종을 확인했다.
- **브라우저 미확인.** 샌드박스에서 로컬 서버 바인딩이 거부됐고 헤드리스 Chrome이 종료 코드 134로 중단됐다. 실제 화면 배치, 타종음, 콘솔, 프레임 속도는 브라우저에서 확인이 필요하다.

## 계약과 통합

- `src/contracts.js`와 Part B 소유 파일을 변경하지 않았다. 계약 변경 제안은 없다.
- Part B 병합 전에는 기존 게임이 모델 버튼과 스님 대화를 사용한다. 동물 대화, 채워진 일지, 모델 목록 및 부탁 단계별 대상 활성화는 Part B 연결이 필요하다. 현재 게임은 `setTargetEnabled`를 호출하지 않으므로 이 상태에서는 우물 부탁을 진행할 수 없다.
- Git이 이 워크트리의 `index.lock` 생성을 거부했다. 변경 파일은 `plan4-play` 워크트리에 남겼다.
